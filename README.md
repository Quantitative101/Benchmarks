# Benchmarks
Collection of benchmark results from my own personal machines.

Methodology:

- NO Wi-Fi or Ethernet at the time of benchmarking! (Except for tests like Geekbench that REQUIRE IT)
- Always using the same settings for ALL devices!
- Divide between "Legacy" and "Modern" so that relevant benchmarks can be used in a way that makes scores comparable WITHIN similar devices.
- Whenever possible, one "Bridge" device (Ex: Vostro 3300) that runs Legacy benchmarks and Newer ones. Keep in mind that a "Bridge" device can look better or worse compared to reality depending on which benchmark it runs, intended only for rough comparisons!
- If devices changes configurations, they will receive separate entries ONLY on the benchmark files, NOT in the ReadMe!
- Background apps always disabled.
- Same resolution used for GPU tests (SPECIFIED IN THE BENCHMARK FILE!)

Q/A:

Q: I have the same config and it performs X% better or worse!
A: These scores are all taken from real devices, running real OS's, stuff like background processes, updates currently installed, OS version or even room temperature CAN affect results. I do my best to make the scores clear and comparable though.


Q: Can you benchmark X config?
A: Only hardware I have on hand will be benchmarked, you are free to request a different configuration scores, such as X laptop but with different ram configs, or X benchmark with different settings, but I can't do everything, slight variations such as ram/storage/OS/ can be requested though!

Q: Why are you doing this?
A: I like tech, it's quite literally my hyperfocus, and I've always found benchmarks, specially cross comparable ones to be a fun way to look at how far we've come.
