# Benchmarks

A collection of benchmark results from my personal machines, documenting hardware performance across different eras.

## Methodology

To ensure results are as consistent and comparable as possible, all tests follow these strict rules:

* **Offline Mode:** No Wi-Fi or Ethernet enabled during benchmarking (unless the software, like Geekbench, requires a connection).
* **Consistency:** The exact same settings are applied across all devices being compared.
* **Environment:** Background applications are fully disabled, and a consistent resolution is used for all GPU-based tests.
* **Hardware Changes:** If a device's hardware configuration is modified, it will receive a **separate entry** in the benchmark files to reflect the change.

---

## Testing Categories

I divide benchmarks into two main categories to ensure scores are comparable within similar hardware classes:

1.  **Legacy:** Older hardware and vintage systems.
2.  **Modern:** Current-gen hardware and recent releases.
3.  **Transition** Middle-ground hardware.

## Q&A

### I have the same config and it performs X% better/worse!
These scores are taken from real-world devices running full Operating Systems. Factors such as specific OS versions, installed updates, minor background processes, and even **room temperature** can cause variations. I aim for clarity, but some margin of error is natural in real-world testing.

### Can you benchmark a specific configuration?
I can only benchmark hardware I physically own. However, you are welcome to request:
* Different RAM configurations on existing hardware.
* Specific benchmark settings or different OS versions.
* *Note: I will do my best to accommodate these, but I cannot guarantee every variation.*

### Why are you doing this?
Tech is my hyperfocus. I find cross-comparable benchmarks to be a fascinating way to visualize exactly how far computing power has evolved over the years.
